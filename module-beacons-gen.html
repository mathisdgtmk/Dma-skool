IMPORTER SUR BEACONS
Suis ces étapes exactement pour avoir ta page live en moins de 20 minutes.
1
Connecte-toi à Beacons
Va sur beacons.ai → clique sur ton profil → Edit Page. Tu vas voir ton éditeur de page.
2
Crée un nouveau produit
Clique + Add Block → choisis "Store Item" ou "Payment Link". C'est là où tu mets ton produit avec le prix.
3
Upload ta miniature
Dans le Store Item → clique sur l'image → Upload → sélectionne ta miniature 1080x1080. Important : fond sombre et texte lisible.
4
Colle le titre généré
Copie le Bloc 1 — Titre généré par l'IA et colle-le dans le champ Product Name de Beacons.
5
Colle la description complète
Copie tous les blocs générés (hook + problème + solution + bénéfices + offre + CTA) et colle-les dans le champ Description. Beacons garde le formatage.
6
Configure le prix
Entre le prix dans Price. Active "Show original price" pour afficher le prix barré. Entre le prix barré dans le champ prévu.
7
Ajoute le lien après achat
Dans Redirect URL after purchase colle :
mathisdgtmk.github.io/Dma-skool/merci-achat.html
8
Publie et teste
Clique Save → Publish. Ouvre ta page en navigation privée et teste le parcours d'achat de A à Z avant de la partager.
